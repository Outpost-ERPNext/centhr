# Administration

This section is for central administrators. The administration screens are in Desk, the standard HR site interface. To open Desk from CentHR, select your name in the menu, then **Open Desk**.

| Page | Read it to |
|---|---|
| [CentHR Settings](settings) | Connect company sites, set failure alerts and set up IOU approvals |
| [Sync and the API Logger](sync-and-api-logger) | See what CentHR sends to the company sites, and resync failures |
| [Data Migration Tool](data-migration) | Copy existing records from a company site into CentHR |
| [Add a Company](add-a-company) | Bring a new group company onto CentHR |
