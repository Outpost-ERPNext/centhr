# Navigating CentHR

Every CentHR screen has the same layout. A menu on the left holds the modules. The work area is on the right.

## The menu

The menu has these groups:

| Group | Screens |
|---|---|
| **Dashboard** | The start page with a summary of HR activity |
| **Architecture** | A diagram of how CentHR connects to the company sites |
| **Docs** | This documentation. It opens in a new tab |
| **Employee Master** | Employees, Leave Allocation, Shift, Holiday List, Org Master |
| **Attendance & Leaves** | Attendance, Attendance Request, Employee Checkin, Leave Type, Leave Application |
| **Payroll** | Payroll Processing: Payroll Dashboard and Salary Slip |
| **IOU** | IOU Dashboard |

**Org Master** holds the setup records: Department, Grade, Designation, Cost Center, Channel, Employment Type, Gender and Salary Structure.

You see only the screens that your role permits. If a screen is not in your menu, ask your administrator for access. See [Roles and Access](roles-and-access).

Use the arrow at the top of the menu to collapse or expand it. CentHR remembers your choice.

## List screens

Each module opens on a list of records. On a list you can:

- Search by name or ID.
- Filter by company, department, employee, status and date.
- Select a total or a status badge to filter the list to those records.
- Select a row to open the record.
- Select **New** to create a record.

Status badges use colors, so open, approved, rejected and pending records are easy to find.

## Record screens

A record screen shows the fields of one record, grouped in tabs. The side panel shows a summary and links to related records.

At the bottom, the **Activity** area shows who changed the record and when. You can add a comment there.

Buttons such as **Submit**, **Approve**, **Cancel** and **Delete** show only when you have permission to do that action.

## Your account menu

Select your name at the bottom of the menu to open the account menu. It has these options:

- **Dark theme** or **Light theme** changes the display theme.
- **Open Desk** opens the standard HR site interface.
- **Log out** ends your session.
