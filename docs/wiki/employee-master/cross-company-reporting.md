# Cross-Company Reporting

An employee can report to a manager who works for a different group company. For example, a finance officer in one company reports to the group finance controller in another company.

## Set a cross-company manager

1. Open the employee record and select **Edit**.
2. Select **Cross Company Reports**.
3. In **Cross Company**, select the company of the manager. You cannot select the company of the employee.
4. In **Reports To**, select the manager. The list shows only active employees of the selected company.
5. Select **Save**.

## What CentHR does with access

When you save, CentHR gives the user of the manager access to this employee and to the company of the employee. The manager can then see and approve the requests of the employee.

CentHR adds access only. It does not reduce what the manager could already see.

When the reporting line changes, or the employee record is deleted, CentHR removes this access. It keeps any access that the manager still needs for other employees.

:::note
The manager must have a user linked to their employee record. Without a user, CentHR cannot give access.
:::
